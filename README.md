# Раломекс — концепция за начална страница

Концепция от ARISE за „Раломекс“ АД, Завет. **Не е официалният сайт на Раломекс.**
Съдържанието, логото и снимките на машините са от https://ralomex.com (виж `assets/ralomex/sources.md`).
Атмосферните снимки са генерирани в Higgsfield (виж `assets/generated/PROMPTS.md`).

Статичен сайт: `index.html`, `css/style.css`, `js/main.js`. Без build стъпка, без библиотеки.
Страницата е скрита от търсачки (`noindex, nofollow`).
